# mushroom-amuta

Volunteer project supporting an Israeli amuta working on medicinal mushrooms (פטריות מרפא):
evidence-graded notes, an Israeli trial tracker, and small tools.

**Not medical advice.** Nothing here diagnoses, treats, or recommends treatment. Evidence levels (E0–E4) are
shown next to every claim. Psychedelic substances (e.g., psilocybin) appear only as summaries of published
research and public trial registries — no cultivation, sourcing, dosing, or promotion.

See `BRIEF.md` for scope and stages.
